# Website Portfolio

Single-page, static portfolio site.

## Deploy
Upload this folder to GitHub and import it into Vercel, or drag the folder into any static host.

## Edit projects
All projects are stored in the `projects` array near the bottom of `index.html`.

Each project has:
- `name`
- `slug` (used to form `https://SLUG.vercel.app`)
- `industry`

Projects marked `Other` can be recategorized later without changing any of the filtering code.
